# Portable distribution receiving

The main-layout distribution subset retains the existing provider installers and trees. It does not import the experimental SDK adapter lifecycle or change publication policy.

Author receiving on Windows used the already qualified CPython 3.15.2 runtime and its original evidence record, not a freshly invented qualification digest. The builder verified input and copied runtime/notices against that same record. After relocation to a directory containing spaces and Unicode, both provider help routes completed through the generated PowerShell entry with empty PATH and invalid PYTHONHOME/PYTHONPATH. No bytecode files appeared.

Separate isolated project installations for Codex and Claude completed using the relocated runtime and the repository's deterministic offline Codex hooks inventory fixture. Readback found twelve Codex and thirteen Claude registered commands bound to that supplied interpreter. This verifies installer wiring, not native provider trust or model execution. Codex retained its existing warning about the rendered standalone instruction document potentially exceeding the effective client budget.

Focused tests cover launcher resolution, missing runtime, create-only assembly, pre/post-copy registered artifacts and mirror parity, and restoration of the temporary module registration. Injected copied-hook corruption prevents the final bundle manifest from being written.

## Limits

- The existing provider lifecycle and shared-skill projection model remain unchanged.
- Relative bundle launch does not make already registered absolute hook paths relocatable. Retain the selected runtime while its installations reference it.
- Local consistency checks are not release authentication or concurrent-hostile-writer protection.
- No native host activation, model call, cross-platform qualification or automatic update was performed.
- The SDK adapter-tree migration remains a separate change requiring explicit preservation of current main behavior.

## Terms and Abbreviations

- SDK: software development kit.
- PATH: operating-system executable search path.
- CPython: the reference Python interpreter implementation.
