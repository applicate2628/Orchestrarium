# Квалификация пакетов Orchestrarium и предварительные просмотры установки

Дата результатов: **24 ноября 2026 года**. Платформа выбранного пакета: **Windows x64**, целевая платформа Rust — `x86_64-pc-windows-msvc`.

Сохранена и первоначальная неудача испытательной среды: слишком длинное временное имя pack-файла Git в варианте SHA-256 завершило два метода **до входа в сканер**. ## 9. Три отдельные записи отказа Claude

### 9.1. Запись 1 — pre-SDK: несогласованный транспортный набор

Первоначальный пакет pre-SDK наблюдал отказ:


### 9.2. Запись 2 — SDK: первоначальный отказ и пропущенная квитанция


Сам выбор собственного владельца Claude задаётся в том же точном источнике около строк 15147–15162. До последующего допуска транспортного набора SDK на строке 10651 выполнение **не дошло**. Причина старого `atomic-projection-state` не переносится на этот остановленный просмотр.

Собственная квитанция не входила в исходные 971 объект и 612 хешей. Эта неполнота остаётся в первоначальной записи; поздний повтор её не переписывает. Хеш первоначальной сводки Claude — `7f5f2fdb5bb2321e93038001f91b27ad1a38ebf09939f084c07e69660dac5115`.

Поздние наблюдения имеют собственное время, набор и результат; они не создают недостающую историю задним числом. Все три отказа Claude остаются отдельными записями.

## 13. Термины и сокращения

- **API — Application Programming Interface:** программный интерфейс сервиса или компонента; живые API провайдеров в этой квалификации не вызывались.
- **Blob:** объект Git, содержащий байты файла.
- **Callback:** функция обратного вызова; Git pre-push callback запускается самим Git перед отправкой.
- **Cargo:** штатный инструмент зависимостей, сборки и тестирования Rust; `Cargo.lock` закрепляет разрешённые версии входов.
- **CLI — Command-Line Interface:** командный интерфейс; `gh` — GitHub CLI.
- **CPython:** реализация Python, использованная в пакетной среде выполнения.
- **CRT — C Runtime:** библиотека выполнения языка C; статическая CRT включена в выбранный обработчик при сборке.
- **DLL — Dynamic-Link Library:** динамически подключаемая библиотека Windows; проверенные импорты выбранного обработчика перечислены в разделе 3.
- **Git commit / tree:** коммит задаёт снимок и его историю; дерево задаёт имена, режимы и содержимое отслеживаемых файлов. Разные коммиты могут иметь одно дерево.
- **Inventory, ведомость:** перечисление выбранных файлов с их точными хешами; связывает результат с реальным составом.
- **Job, Windows Job object:** объект Windows для владения созданной группой процессов и проверки её завершения.
- **Lead:** управляемый навык Orchestrarium; авторское установленное содержимое требует отдельного решения при несовпадении с квитанцией.
- **Manifest:** машинное описание состава или принадлежности набора.
- **MSVC — Microsoft Visual C++:** инструментарий и соглашения целевой платформы выбранной Windows-сборки.
- **Native / range:** в таблице 5 — два полных входа сканера: выбранные Git-объекты и диапазон публикации. Это не синоним фактического Git callback.
- **Notices:** сопровождающие уведомления и полные тексты применимых лицензий.
- **PCRE2 — Perl Compatible Regular Expressions, версия 2:** библиотека регулярных выражений внутри выбранного Rust-обработчика.
- **Peer:** соответствующий производный набор у другого владельца, который проверяется относительно канонического набора.
- **Placeholder / recall / offline:** признаки файлов, чтение которых может потребовать подгрузки облачного содержимого; такие файлы не читались в описанном предварительном допуске.
- **POSIX — Portable Operating System Interface:** стандарт интерфейсов Unix-подобных систем; имя роли в таблице 4 не утверждает нового запуска на такой платформе.
- **PR — Pull Request:** запрос на включение изменений в репозиторий.
- **Pre-SDK:** предшествующий пакет с собственной привязкой исходника, состава и результатов.
- **Receipt, квитанция:** машинная запись проверенного состояния или результата; здесь различаются квитанции сканера публикации и установленного Lead.
- **Retained package, сохранённый пакет:** независимый пакет, созданный штатным `--retain-only` с проверяемой принадлежностью обработчика и среды выполнения.
- **Runtime:** среда выполнения приложения; здесь существующий Python со стандартной библиотекой.
- **SDK — Software Development Kit:** набор средств разработки; название этапа не означает активацию провайдерских SDK.
- **SHA-1 / SHA-256 — Secure Hash Algorithm:** алгоритмы контрольных сумм. В тестовых форматах Git оба обозначают идентификаторы объектов; остальные полные контрольные суммы отчёта — SHA-256.
- **Subtest, подслучай:** отдельное параметризованное условие внутри тестового метода; количество подслучаев не заменяет число полных сравнений.
- **UTC — Coordinated Universal Time:** всемирное координированное время.
- **V2 / Version 3 / Version 4:** разные версии соответствующих форматов: v2 в разделе 9 — представление дерева Lead; Version 3 и Version 4 в разделе 6 — доказательства покрытия публикации. Они не являются одним протоколом.
- **Worktree:** рабочая копия репозитория, связанная с конкретным состоянием Git.
- **PASS / REFUSED:** успешное завершение выбранной проверки / штатный отказ допустить выбранное действие. REFUSED не означает, что установка была применена.
