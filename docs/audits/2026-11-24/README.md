Размер — **1 058 304 байта**. Новая сборка Rust для окончательного SDK не требовалась: соответствующие исходные файлы не изменились. При этом пять из десяти Python-владельцев сканирования отличаются от старого `cee7521e`; поэтому выполнены собственные 24 сравнения окончательного SDK. Их полный перечень и признаки совпадения результатов опубликованы в [scanner-comparisons.csv](scanner-comparisons.csv).

До публикации каждой исправленной ветки выполнены штатные проверки. Публикация PR №19 получила свежие результаты Version 3/Version 4 настоящего Git callback. Ручной скан или сохранённая контрольная сумма не заменяли этот допуск. Это отдельное доказательство от тестовых сравнений сканера.

## 6. Пакет и установленная система

Полный отчёт находится в [qualification.md](qualification.md); разделы `package` и `installedPreviews` [evidence.json](evidence.json) сохраняют машинные результаты.

У окончательного пакета **685 файлов приложения** побайтово совпадают с выбранным исходником и сохранённой копией; **1 210 файлов среды Python** совпадают между собранной и сохранённой копиями. Во время предварительных просмотров неизменны все **1 901 файл пакета**. Десять этапов проверки пакета завершились с полным захватом результатов и закрытием ресурсов.

Одинаковый `bundle.json` у предыдущего и нового пакета ожидаем: этот манифест описывает загрузчик, среду выполнения, обработчик Rust и лицензии, но не идентичность всего приложения. Идентичность SDK подтверждается отдельно исходным коммитом и полной ведомостью файлов приложения.

Наблюдаемое дерево отличается от записанного в квитанции; разрешение на замену не передавалось, поэтому `_preflight_canonical_skills` остановил операцию на строке 10518 точного исходника пакета. До проверки транспорта на строке 10651 выполнение **не дошло**.

Наблюдаемое дерево Lead содержит 82 файла и 10 каталогов. Кандидат нового SDK отличается от него на **10 добавлений, 52 изменения и 0 удалений**. Это сравнение установленного дерева с новым источником, а не количество пользовательских правок относительно неизвестного содержимого старой квитанции. Напечатанный установщиком кандидат выбора не применялся.

Отдельный предварительный просмотр общих обработчиков Codex подтвердил 12 зарегистрированных обработчиков и 22 неизменных выбранных управляющих объекта. Без точного ранее сохранённого выпуска проверка отказала; с явной привязкой к этому выпуску прошла за 9,818 с. Это проверка плана; замена обработчиков и изменение их нативного доверия не выполнялись.

Применения установки, новых живых вызовов провайдеров или моделей в этом аудите не было. Более ранние явно разрешённые живые проверки в истории PR №19 сохраняют свои собственные версии и границы; они не становятся проверкой текущего установленного пакета. Исходники, обязательные доказательства и средства восстановления сохранены; подтверждённо ненужные завершённые временные объекты перемещены в trash без очистки корзины.

## 7. Оставшийся минимальный план

Репозиторные исправления и интеграция уже выполнены. Для перехода к работе выбранного установленного выпуска остаются три зависимых действия:

1. **Согласовать судьбу изменённого Lead Claude.** Рассмотреть конкретное установленное дерево и полный подготовленный кандидат; принять отдельное решение о сохранении, переносе нужных изменений или разрешённой замене. Текущее разрешение на публикацию отчёта не разрешает замену.
2. **Проверить и применить выбранную установку после этого решения.** Пройти оставшиеся проверки транспорта и владения на актуальном состоянии, затем выполнить допущенное применение и контроль установленного результата. Для общих обработчиков отдельно нужна корректная сохранённая среда у всех потребителей и предусмотренная нативная проверка доверия.
3. **Подтвердить выбранный живой сценарий провайдера, когда он будет разрешён.** Зафиксировать точный источник, установленный пакет, маршрут и результат. Остальные провайдеры и платформы сохраняют явно непроверенную область.

Linux-сборка Rust, полный большой пользовательский корпус, произвольная отмена PCRE2 и производственный диспетчер `native/operations` этим результатом не квалифицированы. План из трёх действий не объявляет эти независимые будущие области обязательными для каждого выпуска.

Этот каталог является переносимой публикацией результатов: его можно читать из PR и после клонирования репозитория. В нём нет зависимости от путей к рабочей машине.

- [verification-cases.csv](verification-cases.csv) содержит результаты отдельных тестовых случаев для перечисленных запусков; строки разных запусков не означают уникальные тесты.
- [scanner-comparisons.csv](scanner-comparisons.csv) содержит 24 полных сравнения окончательного SDK и проверенные признаки совпадения.

- Источники [1](#источник-1)–[6](#источник-6) ведут к принятому коду и контрактам.

В `evidence.json` значения `originalSha256` относятся к сохранённым первоначальным записям, а не к отредактированным публичным сводкам. Перенос сохраняет численные результаты и версии, заменяет персональные пути логическими именами и исключает сырые журналы, токены выбора, идентификаторы процессов и личные данные. Сами результаты присутствуют здесь; хеш не служит заменой описанию результата или разрешением на установку/публикацию.

Документация не содержит исполняемых пакетов и не объявляет бинарный релиз. Исходники исправлений уже находятся в перечисленных PR; сведения о составе и идентичности проверенного пакета опубликованы в этом каталоге.

## 10. Термины и сокращения

- **CSV** — comma-separated values, таблица с разделёнными запятыми значениями.
- **JSON** — JavaScript Object Notation, текстовый формат структурированных данных.
- **Codex / Claude** — выбранные клиентские среды соответствующих провайдеров; успешный тест синтетического клиента не доказывает живой вызов.
- **Git commit / tree** — коммит истории / идентификатор дерева файлов. Разные коммиты могут иметь одинаковое дерево.
- **Git callback** — настоящий обратный вызов штатного Git при публикации; он отличается от прямого запуска функции сканера в тесте.
- **Lead** — роль координатора Orchestrarium и соответствующий установленный набор инструкций.
- **main** — основная ветка репозитория.
- **npm** — Node Package Manager, инструмент доставки пакетов экосистемы Node.js; в №17 зафиксирован план канала.
- **PASS / FAIL / REFUSED** — успешный результат / неудачная проверка / контролируемый отказ выбранной операции.
- **PCRE2** — Perl Compatible Regular Expressions, версия 2, библиотека регулярных выражений.
- **PR** — pull request, запрос на включение изменений.
- **SDK** — software development kit, набор средств разработки.
- **SHA-1 / SHA-256** — семейство Secure Hash Algorithm; здесь идентификаторы Git и контрольные суммы содержимого. Они связывают результат с точными байтами, но сами не доказывают поведение.
- **UTC** — Coordinated Universal Time, всемирное координированное время; Москва в указанную дату — UTC+3.
- **Windows Job** — объект Windows для владения деревом процессов и контроля его завершения.
- **Квитанция** — запись, связывающая фактический результат или установленное содержимое с его владельцем.
- **Транспортная проекция** — согласованный производный набор файлов для конкретного клиента, связанный манифестом.
