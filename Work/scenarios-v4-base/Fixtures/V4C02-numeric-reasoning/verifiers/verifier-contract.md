# V4C02 Verifier Contract

Each numeric ID is one independent 10-point atom with oracle-owned full- and zero-credit tolerances.
Credit decreases linearly between tolerances. Non-finite values or wrong units zero only that numeric
atom. Invariant sets use F1; falsification cases score independently. Prose is ignored.

Scorer-side faults return `SCORER-ERROR` with no numeric score.

## Terms and Abbreviations

- `F1`: harmonic mean of precision and recall.
