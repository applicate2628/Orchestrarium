# G05 Fixture - Toolchain Or Build-Break Diagnosis

## Goal

Diagnose the most likely root cause of the build failure, propose the smallest safe fix, and explain how to reproduce the diagnosis.

## Expected artifact

- root cause
- smallest safe fix
- reproduction steps
- confidence and risks

## Inputs

- `build-break.md`

## Hard constraints

- do not blame the last visible error if an earlier configuration failure explains it better
- keep diagnosis reproducible
