# G09 Fixture - Accessibility And UX Review

## Goal

Review the provided static UI artifact and report the most important accessibility and UX issues with severity and rationale.

## Expected artifact

- findings list
- severity
- user impact
- recommended next fix order

## Inputs

- `review-target.html`
- `user-flows.md`

## Hard constraints

- do not mix purely cosmetic critique with blocking accessibility issues
- prioritize issues by user impact
