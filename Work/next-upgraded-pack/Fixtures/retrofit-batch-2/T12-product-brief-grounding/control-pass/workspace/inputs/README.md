# G02 Fixture - Product Brief And Scope Clarification

## Goal

Write a compact product brief that resolves the main ambiguity, names missing facts, and proposes the smallest safe first slice.

## Expected artifact

- problem statement
- user value
- clarified scope and out-of-scope
- open questions
- recommended first slice

## Inputs

- `intake-notes.md`

## Hard constraints

- do not silently choose a large redesign
- keep missing facts explicit
