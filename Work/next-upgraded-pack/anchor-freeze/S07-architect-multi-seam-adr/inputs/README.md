# Inputs

This directory is the immutable packet for the `S07` architect scenario. It provides the accepted
research artifact chain that the architect must use to make the design decision without inventing
new facts.

## Included materials

- `task.md` defines the benchmark task and the required design-package output
- `accepted-brief.md` states the admitted problem, constraints, and protected surfaces
- `factual-repo-memo.md` records the accepted repository facts relevant to this decision
- `competing-seam-options.md` lists the plausible seams and their factual tradeoffs
- `dependency-map.md` shows the current dependency direction and the protected global boundaries

The inputs are architecture-specific. They are intentionally written so a generic research memo or
planner-style phase breakdown will miss the required seam choice, boundary protection, or claims
section.
