# Scoring Anchors

The diagnostic scorer should reward:

- exact option choice and every case witness
- numerical invariants for p95 convention, bounded histogram exactness, Welford/Chan merge, and no clamped variance
- stale-source rejection and non-claim discipline
- document-only scope control
- falsification coverage for cancellation, percentile boundary, shard imbalance, memory, and stale-source traps
