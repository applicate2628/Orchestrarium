# Candidate Root

This is the mutable run root copied for each scored execution.

Only `algorithm-invariant-proof-memo.md` is editable. The file starts as an incomplete template and
must be turned into a full algorithm-scientist artifact using the evidence packet in `../inputs/`.

## Editable file

- `algorithm-invariant-proof-memo.md`

## Read-only context

- everything under `../inputs/`
- everything under `../oracle/`
- everything under `../verifiers/`

The intended behavior is to formalize the rerun-planning problem before implementation. Do not
widen the work into code patches, generic architecture prose, or security/performance policy
packages.
