# Scoring Anchors

N87 scoring distinguishes binary verifier status from a rubric:

- benchmark admissibility: warm-cache-only evidence must not justify approval
- cache-boundary diagnosis: price cache identity must include region and sorted feature flags
- memory-lifetime diagnosis: catalog refreshes must not leave unbounded global retained state
- false-positive restraint for JSON serialization, decimal rounding, and markdown formatting
- response-gate decisions, exact `REVISE` outcome, phase discipline, and exact review-artifact scope
