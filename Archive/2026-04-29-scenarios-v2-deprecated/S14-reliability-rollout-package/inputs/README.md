# Inputs

- `task.md` defines the reliability-engineer ask and required package shape
- `service-and-traffic-brief.md` describes the publish flow and traffic modes
- `incident-trace-and-slo-notes.md` records observed failures and operator expectations
- `failure-mode-notes.md` lists what the current draft gets wrong
- `rollout-envelope.md` defines the promotion and rollback envelope the package must respect
- `degradation-boundaries.md` fences what the package may and may not recommend
