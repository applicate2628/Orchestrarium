# Review Boundary

This bundle is a report-only UI regression gate for a bounded Qt dialog surface.

## In scope

- reproducible keyboard and focus regressions
- high-DPI layout regressions
- theme-variance rendering regressions
- stable checks that prove nearby controls did not all fail together

## Out of scope

- code patching or implementation repair notes
- acceptance-criteria mapping, bug-registry bookkeeping, or release sign-off language
- accessibility findings such as semantic naming, assistive-technology exposure, or contrast-only
  audit language
- UX findings such as copy quality, information architecture, or workflow redesign
- browser-only reruns or overlay requirements
