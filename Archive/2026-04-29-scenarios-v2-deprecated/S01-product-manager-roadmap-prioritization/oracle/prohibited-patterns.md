# Prohibited Patterns

The package loses scope-discipline or role-fidelity points if it does any of the following:

- rewrites the task as a product brief, user-research agenda, or new discovery plan
- offers consultant-style neutral options instead of making an owner decision
- adds lead-style work-item status, routing packets, or resume-point language
- turns the package into implementation planning, code changes, commands, or verifier edits
- prioritizes `Immediate publication rerun` ahead of `Final coverage wave and rerun readiness`
- promotes `Browser overlay expansion` or `Archive and README cleanup` into a top-two roadmap slot
- ignores the gate order or the single rerun-window constraint
- claims the roadmap is approved without naming explicit priorities and deferred items
