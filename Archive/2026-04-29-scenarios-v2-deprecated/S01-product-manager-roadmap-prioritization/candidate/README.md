# Candidate

This directory is the mutable run root copied per execution.

## Editable surface

Only `roadmap-decision-package.md` is editable for the scored run.

## Output contract

The completed file must remain one product-manager-owned roadmap decision package. It must not turn
into:

- a product-analyst brief or new discovery memo
- a consultant recommendation memo or non-blocking note
- a lead routing packet, status ledger, or recovery artifact
- an implementation workspace, code patch, command log, or verifier edit
- a results rerun log or publication-table artifact

Follow the section structure already present in the template so the verifier can check the package
without reinterpreting it.
