# Непрерывность MCP — дополнение Claude Code

Каноническая общая семантика: [shared/references/ru/mcp-continuity.md](../../shared/references/ru/mcp-continuity.md).

## Привязка к runtime Claude Code

Claude Code устанавливает три адаптера под своим паком агентов:

- `~/.claude/agents/scripts/mcp-usage-reminder.py` на `SessionStart`
- `~/.claude/agents/scripts/turn-anchor-reminder.py` на `UserPromptSubmit`
- `~/.claude/agents/scripts/check-mcp-momentum.py` на `PreToolUse`

Запись momentum использует точный matcher `Grep|Bash|PowerShell|shell_command|exec_command`. Нативный `Grep` и четыре shell-имени инструмента входят в один общий классификатор; `exec_command` читает `cmd` и принимает `command` как совместимую форму.

Адаптер передаёт необработанный `cwd` конверта без изменений. Только общая политика находит ближайший корень репозитория и даёт освобождение четырём точным поддеревьям корня репозитория; совпадающий сегмент на другой глубине, недоступная координата или одна неосвобождённая область освобождения не дают.

При `mcpMode: auto` и для конвертов с `agent_id` квалифицирующий поиск сохраняет
видимый модели warn-only advisory через `hookSpecificOutput.additionalContext`.
В корневом диалоге с эффективным `mcpMode: force` каждый квалифицирующий поиск
запрещается через `permissionDecision: deny` с `[MCP-FORCE-1]`, если настроен
подходящий сервер. Предыдущий вызов MCP не даёт зачёта. Точный
`[approve-mcp-fallback:v1]` в ограниченной host-projected записи с ролью `user`
разрешает только этот recovery-ход; инъекция текста ассистента или инструмента
разрешение не создаёт. Проекция не является аутентифицированной авторизацией,
и поддельная host-shaped user JSONL-запись может удовлетворить маркеру. При отсутствии
серверов или неразрешённом режиме действие допускается с
`[MCP-FORCE-NO-SERVER]` или `[MCP-FORCE-MODE-UNRESOLVED]`, что предотвращает
цикл повторов. Внутренние ошибки обрабатываются fail-open. Вспомогательный
модуль политики устанавливается рядом со scripts, но не имеет собственной
регистрации хука.

Регистрация и проверка исходников доказывают путь события, но не установленное
force-поведение. Post-install проверка должна показать повторные запреты
квалифицирующих корневых поисков после успешного MCP-вызова; одна доставка
advisory по-прежнему не доказывает исполнение.

## Термины и сокращения

- `MCP`: Model Context Protocol.
- `PreToolUse`: событие хука перед вызовом допущенного инструмента.
