# Безопасность публикации репозитория — Compatibility Pointer

Канонический общий design reference теперь живёт в [shared/references/ru/repository-publication-safety.md](../../shared/references/ru/repository-publication-safety.md).

Этот pack-local путь сохранён только как compatibility pointer для существующих заметок, отчётов и исторических ссылок.

Распознавание удалённого инструмента не разрешает публикацию; см. общую [границу привязки к целевому хосту](../../shared/references/ru/repository-publication-safety.md#наблюдение-удалённой-команды).
