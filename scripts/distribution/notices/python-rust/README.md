# Python-wheel Rust source notices

This partial supplement retains exact original archive notice bytes for 31 registry source identities reported by the cryptography, jiter, pydantic-core and rpds-py wheel SBOMs. Each archive SHA-256 matches the relevant SBOM component, the retained archive and the earlier source custody record; original paths and exact texts are indexed in source.json.

The 39 component occurrences on each platform include potential build-time inputs. This is conservative source attribution, not proof every component is linked or every legal obligation is satisfied. Remaining components are explicitly unreconciled, not automatically unlicensed. Package-owned Rust modules and separately covered OpenSSL require their own interpretation. Registry metadata/license declarations do not select license alternatives.

The old Codex CLI inventory is only a source of already retained matching archives/texts. Codex CLI and its historical native notice tree remain excluded from the Orche payload. Future runtime changes require fresh component/source reconciliation, not acceptance based on this fixed inventory.
