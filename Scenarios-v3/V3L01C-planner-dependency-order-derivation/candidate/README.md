# Candidate Workspace

Edit only these two files:

- `delivery-order.md` - the delivery-order memo (order, derived dependencies, critical path, readiness
  trace, gate decision).
- `order-witness.json` - the machine-checked witness (phase order, derived edges, critical path, first item).

Do not edit `README.md`, `inputs/**`, `oracle/**`, or `verifiers/**`. The verifier re-derives the correct
order from the explicit edges plus the prose-derived edge; there is no answer key to copy.
