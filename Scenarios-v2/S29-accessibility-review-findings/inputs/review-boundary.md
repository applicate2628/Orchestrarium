# Review Boundary

This gate is scoped to the bundle-local source files and the recorded notes only.

- inspect the seeded dialog source and the immutable observations as evidence
- keep the output in accessibility-review form, not QA-verdict form
- do not ask for a new browser session, screenshot diff, or overlay runner to finish the review
- treat merge blocking as an accessibility gate decision grounded in the provided evidence
- include dynamic status announcement review when submit handlers change visible status text
