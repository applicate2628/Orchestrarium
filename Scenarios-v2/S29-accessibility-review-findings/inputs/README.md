# Inputs

These files are the immutable evidence packet for the accessibility gate.

- `task.md` defines the review assignment and output contract
- `accepted-accessibility-scope.md` records the expected keyboard, naming, state, and contrast
  outcomes
- `keyboard-and-at-observations.md` captures the seeded keyboard walk and screen-reader notes
- `contrast-and-focus-notes.md` records the measured contrast reads used by the gate
- `review-boundary.md` keeps the task findings-only and non-overlay
