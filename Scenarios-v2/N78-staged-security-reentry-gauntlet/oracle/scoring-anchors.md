# Scoring Anchors

- Runtime exploit closure is primary.
- Regression tests, threat ledger, security ledger, exploit validation, reentry state, and closeout
  are scored because this is staged implementation work.
- Exact changed-path scope is required.
- Audit redaction is a runtime security invariant, not a documentation preference.
- Output cost is scoreable so verbose transcripts can lose rubric points without changing binary
  verifier status.
