# N39 Scoring Anchors

The post-run scorer awards:

- binary correctness from runner `summary.json`
- staged phase-path discipline from phase summaries
- patch quality for exact changed-path ownership, test updates, and protected-file avoidance
- implementation-ledger and closeout completeness
- time proxy from staged phase elapsed seconds
- cost proxy from staged worker output bytes

Scores are comparable within this N39 staged surface only.
