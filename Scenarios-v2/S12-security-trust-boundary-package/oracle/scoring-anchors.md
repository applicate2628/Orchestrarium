# Scoring Anchors

These anchors apply the `scientist, constraints` profile to `S12`.

## Strong pass signals

- the package identifies `TB1` through `TB5` and explains what crosses each boundary
- `C1` through `C6` appear as explicit controls rather than vague principles
- the package cites `E1` through `E5` instead of relying on generic security advice
- must-fix items line up with the synthetic dry-run observations
- claims are falsifiable and the final gate decision is `REVISE`

## Common failure signals

- path traversal is mentioned only abstractly and not tied to bundle-controlled manifests
- secret handling is discussed without addressing debug capture or token scope
- provider output is summarized but not treated as untrusted material
- the analyst export is allowed to expose raw stdout, stderr, or vault contents
- the answer drifts into reviewer-style severities or implementation instructions
