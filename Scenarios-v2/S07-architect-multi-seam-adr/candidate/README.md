# Candidate

This directory is the mutable run root copied per execution.

## Editable surface

Only `design-package.md` is editable for the scored run.

## Output contract

The completed file must remain one architect-owned ADR or design package. It must not turn into:

- implementation code or patch instructions
- a planner phase breakdown
- a new factual research memo

The package should follow the section structure already present in the template so the verifier and
downstream reviewers can consume it without reinterpretation.
