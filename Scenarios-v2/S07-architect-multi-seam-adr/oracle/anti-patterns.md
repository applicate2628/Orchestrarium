# Anti-Patterns

The following patterns should lose major points in `S07`:

1. turning the design package into an implementation patch path, script plan, or code diff
2. choosing `Option A` without calling out that it reopens the universal `scenario.yaml` contract
3. choosing `Option C` without calling out that it makes the scorer own scenario-local semantics
4. rewriting the task as generic repo research or planner sequencing instead of architecture
5. omitting dependency direction, protected surfaces, or the numbered claims section
6. proposing changes to score profiles, role taxonomy, publication tables, or adapter boundaries
   even though those surfaces are protected by the accepted inputs
