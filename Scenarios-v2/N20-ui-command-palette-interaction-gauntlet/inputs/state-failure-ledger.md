# State Failure Ledger

| Failure | Expected owner |
|---|---|
| disabled action receives focus | `palette-state.mjs` |
| filter loses stable focus | `palette-state.mjs` |
| escape cannot restore last stable active id | `palette-state.mjs` |
| render omits active descendant | `command-palette.mjs` |
| visible return cue is hidden or absent | `command-palette.mjs` |
| long labels overflow fixed buttons | `palette.css` |
