1. `docs/benchmarks/README.md` still sends readers to
   `archive/2026-03-transition-notes.md` for "current wave status", which now conflicts with the
   accepted source map.
2. `docs/benchmarks/source-of-truth-index.md` does not list
   `docs/benchmarks/wave-3-status.md` as an active canonical source and does not warn that the
   archived transition note is historical only.
3. `archive/README.md` lists `2026-03-transition-notes.md` without a "historical only" label or a
   backlink to the active canonical docs.
4. A draft cleanup suggestion proposes changing governance wording so a knowledge archivist could
   directly update routing-policy semantics when doc drift is found. No accepted decision authorizes
   that change.

The source-of-truth issue is real, but the governance suggestion remains unapproved.
