# Governance Boundary

This scenario tests source-of-truth stewardship, not governance authorship.

## In scope

- correcting stale current-state pointers in the admitted target docs
- restoring canonical-source links
- labeling archive material as historical when needed
- documenting deferred follow-ups when a policy-owned surface is implicated

## Out of scope

- semantic edits to `docs/process/role-routing-policy.md`
- semantic edits to `AGENTS.md`
- creating new gate rules, ownership rules, or reviewer requirements
- inventing a new approval path for the knowledge-archivist role

Any semantic control-plane change requires independent `$architecture-reviewer` approval before it
can be treated as complete.
