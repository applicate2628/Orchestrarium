# Prohibited Patterns

The packet loses scope-discipline or role-fidelity points if it does any of the following:

- treats `archive/2026-03-transition-notes.md` as a current canonical source
- adds update targets beyond the three admitted docs
- rewrites `docs/process/role-routing-policy.md` or `AGENTS.md`
- invents a new approval rule for the knowledge-archivist role
- turns the packet into a delivery plan, review report, or implementation patch
- proposes "cleaning up" archived history by rewriting historical notes instead of fixing pointers
- claims the source of truth is repaired without naming the canonical sources and exact targets
