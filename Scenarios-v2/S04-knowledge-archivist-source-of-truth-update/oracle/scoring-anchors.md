# Scoring Anchors

`S04` uses the shared `owner, advisory, factual, design, planning` score profile, but the local
signals are stewardship-specific.

## Strong pass signals

- names the accepted canonical sources explicitly
- keeps the update target set exact and bounded
- reconciles active docs against active canonical sources instead of archive history
- preserves archive notes as historical records with corrected labels and backlinks
- states that governance or policy changes require independent review

## Point-losing signals

- vague "repo cleanup" language without exact target docs
- treating an archive item as an active authority
- silent governance rewriting or policy invention
- drifting into planning, implementation, or review findings
- declaring the packet complete without addressing archive hygiene and canonical-source links
