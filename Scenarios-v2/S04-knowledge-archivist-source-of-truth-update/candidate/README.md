# Candidate

This directory is the mutable run root copied per execution.

## Editable surface

Only `source-of-truth-update-packet.md` is editable for the scored run.

## Output contract

The completed file must remain one knowledge-archivist-owned stewardship packet. It must not turn
into:

- a lead routing packet or status ledger
- a consultant recommendation memo
- an architecture ADR or plan
- a review findings report
- an implementation workspace, code patch, or diff

Keep the update targets explicit and bounded. Follow the section structure already present in the
template so the verifier can check the packet without reinterpreting it.
