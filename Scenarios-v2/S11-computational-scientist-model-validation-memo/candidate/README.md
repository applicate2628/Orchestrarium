# Candidate Root

This is the mutable run root copied for each scored execution.

Only `model-validation-memo.md` is editable. The file starts as an incomplete template and must be
turned into a full computational-scientist artifact using the evidence packet in `../inputs/`.

## Editable file

- `model-validation-memo.md`

## Read-only context

- everything under `../inputs/`
- everything under `../oracle/`
- everything under `../verifiers/`

The intended behavior is to validate or reject the draft physical model before implementation. Do
not widen the work into code patches, generic architecture prose, security policy, performance
policy, or hardware repair instructions.
