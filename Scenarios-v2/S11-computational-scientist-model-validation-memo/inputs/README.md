# Inputs

This directory is the immutable evidence packet for `S11`.

## Included materials

- `task.md` defines the benchmark task and the required output contract
- `system-brief-and-operating-range.md` describes the physical system and admitted use (`E1`)
- `proposed-model-and-assumptions.md` gives the draft governing equation and assumptions (`E2`)
- `instrumentation-and-trace-data.md` records the measured and predicted validation traces (`E3`)
- `validation-criteria.md` defines the acceptance criteria and physical consistency checks (`E4`)
- `anomaly-notes-and-limitations.md` records the known confounders and data limits (`E5`)

The packet is intentionally specific. A generic "the model looks reasonable" answer will miss the
governing equations, the units and invariants, the profile-level validation failures, and the
explicit uncertainty handling this scenario requires.
