# Scoring Anchors

N60 is a diagnostic separator candidate for single-session UI implementation with visual/state
coupling and reentry evidence.

| Dimension | Points |
|---|---:|
| State-machine correctness | 20 |
| Raster correctness | 25 |
| Accessibility/keyboard semantics | 15 |
| Layout/CSS stability | 10 |
| Patch quality and scope discipline | 10 |
| Regression tests | 5 |
| Ledger/closure evidence | 5 |
| Time/route scoreability | 5 |
| Output/cost | 5 |

Runtime, quota, route, and missing-summary failures are not model semantic failures.
