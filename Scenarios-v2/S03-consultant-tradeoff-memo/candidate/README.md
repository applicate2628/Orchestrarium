# Candidate

This directory is the mutable run root copied per execution.

## Editable surface

Only `advisory-memo.md` is editable for the scored run.

## Output contract

The completed file must remain one consultant-owned advisory memo. It must not turn into:

- a lead routing packet or approval artifact
- a planner phase breakdown
- an implementation patch or task list
- an adapter or provider-transport report

Follow the section structure already present in the template so the verifier can check the memo
without reinterpreting it.
