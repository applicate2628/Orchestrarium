# Evidence Summary

## Confirmed evidence

- Existing first-wave bundles use bundle-local oracle and verifier contracts rather than one shared
  memo schema.
- The universal bundle contract already fixes the six required top-level entries and the
  `scenario.yaml` field set.
- Advisory, factual, design, and planning surfaces share one score profile, but their artifact
  contracts still differ by role.
- The next admitted backlog gap is `R03 $consultant`; later memo-only sibling surfaces include
  `R06 $analyst` and `R10 $algorithm-scientist`.
- Implementation-heavy phases do not need to begin before a memo-only pilot exists.

## Incomplete evidence

- there is no measured authoring-time comparison between a one-off advisory bundle and a shared
  memo scaffold
- there is no proof that `S06` and `S10` will want the same sections as `S03`
- there is no fresh runtime or scoring evidence beyond the already accepted first-wave roots

## Signals that cut both ways

- a shared scaffold might reduce duplicated verifier code later
- pre-abstracting now could freeze the wrong memo shape before the remaining memo roles exist
- waiting for more evidence avoids premature abstraction, but it also delays the first concrete
  signal about memo-bundle ergonomics
