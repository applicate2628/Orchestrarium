# Anti-Patterns

- issuing `PASS`, `REVISE`, or `BLOCKED` as if the consultant were a pipeline gate
- routing work directly to another role as if the consultant owned orchestration
- turning the memo into a phase plan, implementation patch, or architecture package
- recommending score-model, taxonomy, or first-wave-root changes that are outside the accepted
  packet
- treating provider transport, adapter behavior, or external CLI selection as the main problem
- presenting certainty even though the evidence packet is explicitly incomplete
- choosing shared scaffolding first without naming the missing evidence and widened blast radius
