# Inputs

The inputs define the immutable review packet for `N03`.

## Included files

- `task.md` defines the candidate instructions and report boundary
- `accepted-review-scope.md` records the admitted behavior and non-issues
- `repo-context.md` captures the relevant ownership and boundary notes
- `review-boundary.md` keeps the lane generic and findings-only
- `bounded-diff.patch` contains the exact pre-PR change under review

The candidate should cite these files directly instead of inventing new review scope.
