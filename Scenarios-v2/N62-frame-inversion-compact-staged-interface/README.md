# N62 Frame-Inversion Compact Staged Interface Gauntlet

Refactor a small multi-module Python package from legacy ambiguous return interfaces to
structured result objects under a compact single-brief prompt frame.

This is a frame-inversion diagnostic. The visible task is compact, but the verifier still scores the
same hard staged requirements as the N35 class: durable migration state, review-response decisions,
closeout reconstruction, hidden consumer behavior, no compatibility wrappers, exact scope, and
patch-quality discipline.

The intended question is whether staged-ledger failures persist when the prompt is not framed as a
long staged process. A fail here is evidence for a real implementation/re-entry weakness, not just a
style mismatch with staged task wording.
