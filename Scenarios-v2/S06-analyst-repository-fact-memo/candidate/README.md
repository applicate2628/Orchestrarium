# Candidate

This directory is the mutable run root copied per execution.

## Editable surface

Only `repository-fact-memo.md` is editable for the scored run. The repo snapshot is read-only and
is included only so the analyst can cite concrete evidence.

## Output contract

The completed file must remain one analyst-owned factual research memo. It must not turn into:

- design recommendations or ADR content
- a planner phase breakdown
- implementation steps, patch instructions, or code diffs

Keep confirmed facts, false leads, and unknowns in separate sections so downstream roles can reuse
the memo without reopening basic repository discovery.
