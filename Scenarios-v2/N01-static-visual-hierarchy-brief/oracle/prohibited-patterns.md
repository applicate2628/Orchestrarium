# Prohibited Patterns

The following patterns should lose major points in `N01`:

1. solving the scenario with styling polish alone while leaving the information structure unchanged
2. writing a click-flow or state-machine memo when the main pressure is static hierarchy
3. proposing component trees, CSS token sets, route layouts, or widget classes instead of UX
   structure
4. writing an architecture ADR, dependency memo, or storage design note instead of a UX brief
5. producing review findings, severity-ranked bugs, or accessibility-audit language instead of a
   forward-looking design brief
6. leaving shared naming inconsistent across desktop and web
7. letting screenshots, history, or decorative metadata outrank blockers, reviewer asks, or
   publish disposition
