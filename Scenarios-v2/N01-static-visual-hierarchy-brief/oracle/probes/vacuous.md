# N01 UX Structure Brief

- Brief owner: `$ux-designer`
- Surfaces in scope: Windows desktop routing workspace plus web release console
- Artifact boundary: one UX structure brief only

## UX objective

Improve the visual hierarchy and information structure across desktop and web.

## Users and operating context

Operators use desktop and web surfaces.

## Current hierarchy and information-structure failures

- The hierarchy is unclear and information structure is weak on both surfaces.

## Information hierarchy principles

- Use hierarchy, structure, and emphasis. Primary and secondary levels matter.

## Proposed cross-surface information structure

Supporting metadata and screenshots are shown across the surfaces.
Also present: current release verdict, blocker, reviewer ask, evidence freshness.
These are all part of the information structure on desktop and web, with shared naming and
cross-surface labels.

### Desktop workspace hierarchy

- Desktop shows metadata, screenshots, and the release verdict and blocker.

### Web release console hierarchy

- Web shows history, thumbnails, and the release verdict and reviewer ask.

### Shared naming and hierarchy ladder

- Shared naming for the cross-surface labels.

## Proposed static emphasis model

- Primary, secondary, and deferred levels exist on desktop and web.

### Primary focus regions

### Secondary detail zones

### Escalation and exception cues
