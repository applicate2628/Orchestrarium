# Inputs

This directory is the immutable packet for the `N01` UX-design scenario. It focuses on static
visual hierarchy and cross-surface information structure, not implementation planning or review
output.

## Included materials

- `task.md` defines the benchmark task and required UX-brief output
- `accepted-brief.md` states the admitted problem, goals, and protected surface split
- `current-cross-surface-audit.md` describes how the desktop and web surfaces currently group and
  emphasize information
- `hierarchy-and-information-friction.md` records the main hierarchy failures and cross-surface
  label drift
- `boundary-rules.md` clarifies what belongs in UX design versus implementation, architecture, or
  later review output

The packet is intentionally hierarchy-focused. A styling tweak list, implementation plan, or
review-style findings memo will miss the required information-structure work.
