# Scoring Anchors

## Strong brief

- introduces a coherent cross-surface state ladder with explicit ownership
- distinguishes progress states, interruption states, and return-loop triggers
- explains how operators resume work after reviewer questions, validation failures, or paused
  approval work
- keeps the artifact UX-focused and avoids implementation or review drift
- makes publish gating subordinate to unresolved loops or blockers

## Partial brief

- identifies interruption pain but leaves the state ladder incomplete
- proposes a better flow without clarifying ownership or resume cues
- stays mostly UX-focused but drifts into light implementation hints or generic narrative

## Weak brief

- ignores interruptions or return loops
- offers a bug list, audit report, or implementation plan instead of a structure brief
- leaves progress versus holding states unresolved
- makes the workflow read like a one-way wizard with no credible re-entry path
