# Candidate

This directory is the mutable run root copied per execution.

## Editable surface

Only `ux-structure-brief.md` is editable for the scored run.

## Output contract

The completed file must remain one UX-designer-owned structure brief. It must not turn into:

- implementation tickets, code diffs, or component specs
- an architecture ADR or dependency memo
- a review findings report, usability scorecard, or accessibility audit
- a generic user-journey narrative without an explicit state model

The brief should follow the section structure already present in the template so the verifier and
downstream lanes can consume it without reinterpretation.
