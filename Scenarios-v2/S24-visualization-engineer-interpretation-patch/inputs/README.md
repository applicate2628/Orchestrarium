# Inputs

The inputs define the immutable task packet for `S24`.

- `task.md` states the required output and the visualization-specific constraints
- `interpretation-brief.md` defines the expected anomaly and depth semantics
- `boundary-notes.md` spells out the owned seam and the forbidden widening surfaces
- `start-state-observations.md` records the expected broken start-state behaviors
- `section-cases.json` contains deterministic section packets for local validation
