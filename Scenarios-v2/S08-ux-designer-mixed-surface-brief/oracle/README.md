# Oracle

This directory defines the accepted scoring contract for `S08`.

- `ux-brief-contract.json` is the machine-readable bundle and brief contract
- `expected-ux-direction.md` states the preferred flow and state-shape outcomes
- `prohibited-patterns.md` lists the main role-drift and scope-drift failures
- `scoring-anchors.md` summarizes what strong, partial, and weak UX briefs look like

The oracle defines role-correct expectations for a UX structure brief. It does not authorize
implementation patches, architecture ADRs, or review findings as substitute outputs.
