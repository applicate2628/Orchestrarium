# Inputs

This directory is the immutable packet for the `S08` UX-design scenario. It provides the accepted
interaction problem and boundary rules so the candidate can restructure the workflow without
inventing new product scope or implementation work.

## Included materials

- `task.md` defines the benchmark task and the required UX-brief output
- `accepted-brief.md` states the admitted problem, users, goals, and protected surfaces
- `current-cross-surface-audit.md` describes the current desktop and web workflow shapes
- `state-and-flow-friction.md` records the mismatched states, handoff failures, and interruption
  cases that the brief must address
- `boundary-rules.md` clarifies what belongs in UX design versus implementation, architecture, or
  later review output

The inputs are intentionally interaction-design-specific. A generic architecture memo, code patch
plan, or review findings report will miss the required surface restructuring and role boundary.
