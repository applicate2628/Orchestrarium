# Inputs

This directory is the immutable problem packet for `S32`.

- `task.md` is the adapter-only task contract
- `accepted-worker-phase.md` records the assigned internal worker role for provenance only
- `agents-mode.yaml` is the selected dispatch config snapshot
- `runtime-observations.md` is the canonical transport fact set for this run
- `transport-wrapper-notes.md` defines the allowed external-launch behavior and fail-closed rule
