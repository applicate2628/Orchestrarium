# N34 High-Load Science Optimizer Gauntlet

- a high-load Method of Moments solver for TMz scattering by a PEC circular cylinder
- a high-grid finite-difference radial Schrodinger solver for hydrogenic bound states
- N30-style staged/re-entry artifacts that prove the optimization was diagnosed, implemented, optimized, and closed out

The verifier uses analytical physics oracles only for validation. Candidate code must keep edits inside the allowed surface, preserve staged artifacts, and satisfy correctness plus runtime budgets.
