# Непрерывность MCP — дополнение Claude Code

Каноническая общая семантика: [shared/references/ru/mcp-continuity.md](../../../../shared/references/ru/mcp-continuity.md).

## Привязка к runtime Claude Code

Claude Code устанавливает три адаптера под своим паком агентов:

- `~/.claude/agents/scripts/mcp-usage-reminder.py` на `SessionStart`
- `~/.claude/agents/scripts/turn-anchor-reminder.py` на `UserPromptSubmit`
- `~/.claude/agents/scripts/check-mcp-momentum.py` на `PreToolUse`

Запись momentum использует точный matcher `Grep|Bash|PowerShell|shell_command|exec_command`. Нативный `Grep` и четыре shell-имени инструмента входят в один общий классификатор; `exec_command` читает `cmd` и принимает `command` как совместимую форму.

Адаптер передаёт необработанный `cwd` конверта без изменений. Только общая политика находит ближайший корень репозитория и даёт освобождение четырём точным поддеревьям корня репозитория; совпадающий сегмент на другой глубине, недоступная координата или одна неосвобождённая область освобождения не дают.

При `mcpMode: auto` и для конвертов с `agent_id` квалифицирующий поиск выдаёт
видимый модели неблокирующий advisory через
`hookSpecificOutput.additionalContext`. Корневой диалог при эффективном
`mcpMode: force` получает через тот же канал напоминание
`[MCP-FORCE-ADVISORY]`. Действующее force-требование по-прежнему требует
runtime tool discovery, соответствующую схему инструмента и применение
подходящего MCP, включая проверки выбранного корня и актуальности данных, а
также соблюдение существующих ограничений для альтернативных путей. Runtime
discovery — единственный источник доступности; настроенные имена не доказывают
доступность. Advisory прямо оставляет соблюдение требований неопределённым, не
выдаёт разрешение и не отменяет отказы хоста. Неразрешённый режим выдаёт
стабильное диагностическое advisory `[MCP-FORCE-MODE-UNRESOLVED]`. Имена
инструментов в документации — ненормативные примеры, которые никогда не
участвуют в логике выбора. Внутренние ошибки обрабатываются fail-open.
Вспомогательный модуль политики устанавливается рядом со scripts, но не имеет
собственной регистрации хука.

Регистрация и проверка исходников доказывают путь события, но не доставку
установленного force-advisory. Post-install проверка должна подтвердить
идентичность установленного исходника и текущее advisory на представительном
квалифицирующем поиске; это подтверждает доставку, но не соблюдение требования
или поведение модели.

## Термины и сокращения

- `MCP`: Model Context Protocol.
- `PreToolUse`: событие хука перед вызовом допущенного инструмента.
