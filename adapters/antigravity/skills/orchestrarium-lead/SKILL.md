# Native Lead coordination

Apply the installed shared governance and Antigravity addendum supplied at
SessionStart. Establish the requested outcome, current project scope, existing
plan and current permissions before dispatch or changes. Preserve unrelated work.
Delegate bounded work only through actually available, user-authorized native
capabilities. Verify actual results independently where required; role labels,
messages and proposed decisions are not acceptance or execution evidence.

Use existing project lifecycle owners for task state and publication. This
startup pack does not claim native tool enforcement, subagent receipt integration,
or automatic work-item completion. Never simulate those missing capabilities.

## Explicit external Codex SDK review

Use the entrypoint in this same managed package, `scripts/invoke-codex-prompt.py`,
resolved two directories above this skill directory. Do not substitute an
unrelated Codex installation or the development checkout when a component is
missing. This is an external Codex reviewer, not an AGY-native subagent.

Before invocation, use the existing Host to admit the task, select a permitted
model/effort, establish the current account/native trust and spending authority,
and prepare the existing version-1 review binding and actual work-item ledger.
The binding constrains execution; it does not authorize it. Use the selected
Python environment containing the officially provisioned Codex SDK. This pack
does not install that dependency or change authentication.

Pass the existing `--sdk-review-binding`, `--prompt-file`, absolute
`--terminal-receipt`, `--ledger`, canonical reviewer `--ledger-role`, and
`--ledger-artifact` arguments. Supply task-appropriate finite resource settings
through the existing owner; do not invent grants or IDs to satisfy validation.
The selected model and `model_reasoning_effort` remain explicit provider flags.
Omitting the SDK selector chooses a different legacy route, not an SDK fallback.

Receive the actual terminal artifact through the same canonical ledger owner;
an external PASS remains nonauthorizing evidence. Preserve acquired output and
existing recovery/no-replay behavior if interrupted. An advisory hook result,
role label, copied receipt or successful process start does not close a task.
Offline installed-path coverage includes Reviewer and read-only Consultant;
other roles and real AGY-to-Codex native execution require their own qualification. Do not call
the same-provider AGY consumer session as an external worker.
