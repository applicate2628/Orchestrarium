# Little Orche identity

The current project is **Orchestrarium**. Its current mascot is **Little Orche**:
the smallest, round lime-green character, with arms down, red horns, two fangs,
small green wings and a green devil tail with a triangular tip. The larger
Orche and the project rebrand are reserved for after the SDK and Rust transitions.

`orche.png` is a transparent 320 x 304 pixel logo, displayed at 160 x 152 pixels
in the root README. It is a proportional crop and reduction of the rightmost
Little Orche from the approved three-character sheet of 2026-10-29, not a newly
generated design. Only the neighboring character was excluded at the transparent
seam; Little Orche's wings, horns, hands, feet and tail remain intact.
The full-resolution source remains in the owner's artwork library; do not add
large duplicate artwork to the repository.

This is a product asset, not an authority marker. Keep existing receipt/schema,
hook ownership and migration identifiers unchanged unless separately migrated.
