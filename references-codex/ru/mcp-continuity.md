# Непрерывность MCP — дополнение Codex

Каноническая общая семантика: [shared/references/ru/mcp-continuity.md](../../shared/references/ru/mcp-continuity.md).

## Привязка к runtime Codex

Установка Codex восстанавливает руководство по MCP tool discovery и свежести индексных данных через `$HOME/.agents/skills/lead/scripts/mcp-usage-reminder.py` на `SessionStart`, включая compaction. Постоянные правила требуют релевантного поиска инструментов и применения собственной процедуры свежести/восстановления инструмента. Codex не регистрирует аудит поисковой навигации по исходникам.

`$HOME/.agents/skills/lead/scripts/turn-anchor-reminder.py` на `UserPromptSubmit` поддерживает продолжение активной задачи и готовность к делегированию. `$HOME/.agents/skills/lead/hooks/check-parallel-mcp-momentum.py` на `PreToolUse` поддерживает диспетчеризацию готовых корневых задач, утверждённый контекст проекта, отсутствие вложенного делегирования, освобождение ресурсов и компактный контекст. Эти workflow-напоминания не повторяют стартовые правила выбора инструмента и не доказывают соблюдение моделью.

Контекст напоминания передаётся через `hookSpecificOutput.additionalContext`; ошибочные пути остаются fail-open. Вспомогательный модуль политики копируется рядом со scripts, но не является зарегистрированным stem хука. Отдельный классификатор поиска и force-mode адаптер Claude описаны в дополнении Claude Code.

## Обновление и проверка

Текущий набор Codex содержит двенадцать принадлежащих паку записей. Существующий инсталлятор удаляет только точную идентичность принадлежащего паку search-audit: event/matcher/type/command. Пользовательские и несовпадающие обработчики, а также метаданные группы и верхнего уровня сохраняются и отражаются в отчёте; отсутствие принадлежащей идентичности идемпотентно. Reclaim удаляет только совпадающий по хэшу устаревший файл пака.

Для новых или изменённых идентичностей регистрации Codex требует явного доверия. Проверки исходников и синтетические фикстуры не подтверждают число установленных записей, доверие хоста, фактическое использование инструмента или послушание в длинном ходе; переустановка и чтение состояния хоста остаются отдельными проверками.

## Термины и сокращения

- `MCP`: Model Context Protocol.
- `PreToolUse`: событие хука перед вызовом допущенного инструмента.
