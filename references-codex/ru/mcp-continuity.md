# Непрерывность MCP — дополнение Codex

Каноническая общая семантика: [shared/references/ru/mcp-continuity.md](../../shared/references/ru/mcp-continuity.md).

## Привязка к runtime Codex

Codex устанавливает три адаптера под skill Lead:

- `~/.codex/skills/lead/scripts/mcp-usage-reminder.py` на `SessionStart`
- `~/.codex/skills/lead/scripts/turn-anchor-reminder.py` на `UserPromptSubmit`
- `~/.codex/skills/lead/hooks/check-mcp-momentum.py` на `PreToolUse`

Запись momentum использует точный matcher `Grep|Bash|PowerShell|shell_command|exec_command`. Широкий matcher является защитным, поскольку имя инструмента, предоставляемое Codex, менялось между версиями runtime; адаптер всё равно допускает только эти пять имён и применяет общий классификатор к фактическому конверту. Для `exec_command` каноническое поле команды — `cmd`, а `command` принимается как совместимый вход.

Адаптер передаёт необработанный `cwd` конверта без изменений. Только общая политика находит ближайший корень репозитория и даёт освобождение четырём точным поддеревьям корня репозитория; совпадающий сегмент на другой глубине, недоступная координата или одна неосвобождённая область освобождения не дают.

Хук не пропускает конверт только из-за наличия `agent_id`. Попадания корневого и делегированного агента доставляются модели как warn-only advisory через `hookSpecificOutput.additionalContext`; и попадание, и промах завершаются кодом 0, а внутренние ошибки обрабатываются fail-open. Вспомогательный модуль политики копируется рядом со scripts, но не регистрируется как stem хука.

Codex помечает изменённую идентичность регистрации как недоверенную. Поскольку этот релиз меняет matcher существующего MCP-momentum, оператор должен переустановить пакет и явно доверить затронутую запись до заявления о срабатывании установленного варианта. Тесты и валидаторы исходников не проверяют установленный dogfood.

## Термины и сокращения

- `MCP`: Model Context Protocol.
- `PreToolUse`: событие хука перед вызовом допущенного инструмента.
